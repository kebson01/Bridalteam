# Pinterest pins: batch 2, the free tools (2026-10-29)

Drafted for the five free tool pages. **Nothing here is posted.** The owner
reviews each pin before it goes up; once it's posted, mark it `posted` in
`COUPLES-TRACKER.md`.

Every number on a pin comes from the tool it links to:
- the checklist dates come from `lib/plan-template.ts`;
- the budget split comes from `lib/budget-template.ts`;
- the table counts come from `lib/seating-calculator.ts`.

If one of those changes, check the pin before reposting it.

## Before posting

- **Images:** the finished 1000 × 1500 PNGs are in `2026-10-29-batch-2/`,
  named after each pin. They use the same frame, fonts and colors as batch 1.
- **Boards:** all five pins go on boards that already exist on the account.
- **Links:** use each tagged URL exactly as written, so `page_events` can
  count visits per pin (`utm_source=pinterest`).
- **Timing:** space the pins out, for example one a day. Five links to one
  site in a minute can look like spam to Pinterest.
